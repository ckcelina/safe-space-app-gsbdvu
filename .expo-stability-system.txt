╔═══════════════════════════════════════════════════════════════════════════╗
║                      TROUBLESHOOTING GUIDE                                 ║
╚═══════════════════════════════════════════════════════════════════════════╝

  Issue: Server won't start
  Fix:   npm run reset

  Issue: Port conflicts
  Fix:   npx kill-port 8081 19000 19001 19002

  Issue: Cache corruption
  Fix:   npm run clean && npm run dev -- --clear

  Issue: Watchman issues
  Fix:   watchman watch-del-all

  Issue: Frequent disconnections
  Fix:   Check network, increase maxRetries in config
